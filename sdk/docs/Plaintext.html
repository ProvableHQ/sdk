Plaintext

SnarkVM Plaintext object. Plaintext is a fundamental monadic type used to represent Aleo primitive types (boolean, field, group, i8, i16, i32, i64, i128, u8, u16, u32, u64, u128, scalar, and signature), struct types, and array types. In the context of a web or NodeJS application, this type is useful for turning an Aleo type into a JS value, object, or array that might be necessary for performing computations within the application.
